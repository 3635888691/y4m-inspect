# y4m-inspect

拟议中的 MoonBit 增量 YUV4MPEG2 校验器，用于发现头部错误和截断帧，输出帧计数与亮度范围。仓库初始内容是申报说明和合成回归样本，不是已完成的解析器，也不代表赛事已立项。

## 回归样本

| 文件 | 场景 | 判定标准 |
|---|---|---|
| two-frames.y4m | 2×2、8 位单色、25 fps、双帧；首帧像素含换行字节 | 完整两帧，亮度范围 [0,255]、[7,7] |
| truncated.y4m | 上述素材缺最后一个字节 | 第二帧不完整，缺 1 字节 |

原始字节由本项目合成，无需外部视频。机器可读期望见 expected.json。
项目边界与拟交付项见 [项目申报说明](proposal.pdf)。拟实现的流式接口须在输入按单字节或任意分块交付时，保持输出和错误一致。
